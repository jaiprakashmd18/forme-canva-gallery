# FORME — Canva Gallery

Premium static gallery website ready for Vercel hosting.

## Deployment
Import this GitHub repository into Vercel. Framework preset: Other. No build command is required.

## Update designs
Edit `designs.js` to add or change gallery items. Use a publicly accessible thumbnail image URL and a Canva **view** link, never a private edit link.

Features: category filtering, full-screen previews, favorites saved locally, search, responsive layouts.
